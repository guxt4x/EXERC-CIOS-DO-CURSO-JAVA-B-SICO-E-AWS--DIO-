# 🚀 Trilha de Desenvolvimento Java & Orientação a Objetos

Bem-vindo ao repositório dos meus projetos e resoluções de desafios em **Java**! 

Este repositório documenta a minha jornada de desenvolvimento e prática de conceitos fundamentais e avançados da linguagem, construídos através dos exercícios propostos pelo Bootcamp da DIO (Digital Innovation One). O foco principal aqui é a aplicação limpa e escalável da **Programação Orientada a Objetos (POO)**.

## 🗂️ Estrutura do Repositório

O repositório está organizado em módulos progressivos de aprendizado, demonstrando a evolução desde a base da linguagem até o uso de recursos mais avançados:

* **`1-fundamentos-linguagem-programacao`**: Lógica de programação, manipulação de dados de entrada e operações matemáticas básicas.
* **`2-estruturas-de-controle`**: Implementação de fluxos de decisão e laços de repetição de forma otimizada.
* **`3-abstracao-com-classes-e-encapsulamento`**: Modelagem de entidades do mundo real, proteção de dados e criação de métodos seguros.
* **`4-heranca-e-polimorfismo`**: Reutilização de código e sobrescrita de métodos para comportamentos dinâmicos.
* **`5-Dominando-Interfaces-e-Lambda`**: Criação de contratos de código (Interfaces) e uso de `Records` para classes de dados imutáveis.
* **`6-Collections-e-Outras-Classes-Uteis do-Java`**: Gerenciamento de listas dinâmicas (`ArrayList`) e manipulação de tipos genéricos (`<T>`).

## 💻 Destaques e Aplicações Práticas

Para demonstrar o domínio dos conceitos, modelei cenários do mundo real em código. Alguns dos principais projetos que você encontrará aqui incluem:

* 🏦 **Sistema Bancário (Encapsulamento):** Uma aplicação robusta para gerenciar saques e depósitos, contendo lógica condicional complexa para limites de Cheque Especial e proteção de saldo.
* 🚗 **Controle de Veículos (Abstração):** Modelagem do comportamento de um carro, controlando estados rigorosos (ligado/desligado), limite dinâmico de velocidades e troca de marchas segura.
* 🎟️ **Gestão de Ingressos (Herança e Polimorfismo):** Um sistema de bilheteria de cinema que calcula dinamicamente os valores das entradas (Normal, Meia, Família) com regras de desconto baseadas na quantidade de pessoas.
* 📊 **Cálculo de Impostos (Interfaces e Records):** Arquitetura flexível utilizando Interfaces para calcular diferentes taxas sobre categorias de produtos (Saúde, Vestuário, Cultura e Alimentação).
* 🧮 **Calculadora Avançada (Collections e Generics):** Aplicação flexível construída com *Generics* (`<T>`) e `ArrayList` para manter um histórico detalhado das operações matemáticas realizadas.

## 🛠️ Tecnologias e Conceitos Aplicados

* **Java 17+** (Uso de `Records` e *Switch Expressions*)
* **Programação Orientada a Objetos (POO)**
* Estruturas de Dados e Coleções
* Boas práticas de organização de diretórios e nomenclatura
